# BRIEF (ส่งให้ subagent): เติมความลึกเฉลยที่มีอยู่แล้วให้ถึงระดับ Subspe 78 — ใช้ได้ทุกวอร์ด
ห้ามแตะ git · แก้เฉพาะไฟล์ batch ตัวเอง · เขียนไฟล์ด้วย bash heredoc เท่านั้น
ใช้เมื่อวอร์ดมีเฉลยครบช่องแล้วแต่บางกว่าเกณฑ์ (แบบ Subspe 72/76/77) — **ห้ามเขียนใหม่ทั้งข้อ** ข้อความที่ดีอยู่แล้วเก็บไว้ (ผู้ใช้ชอบช่อง wrong ของ 76 มาก)

1. อ่าน `kit78/BRIEF_WRITE.md` (มาตรฐานทุกช่อง + คำต้องห้าม) และ `kit78/EXAMPLES.json`
2. ดูข้อ: `python3 kit78/pk.py <dump.json> <key>…` และช่องเฉลยเดิมใน dump · หาช่องที่ไม่ผ่าน: สร้างแพตช์ว่าง `{key:{}}` แล้วรัน `python3 kit78/gate78.py <dump.json> <แพตช์>`
3. เขียน**เฉพาะช่องที่ไม่ผ่าน**ใหม่ทั้งช่องให้ลึกจริง (กลไก เกณฑ์ ตัวเลข guideline ผู้ป่วยจริง — ไม่ใช่เติมคำ) · summary/variants เก็บ bullet เดิมที่ดีแล้วเติม · wrong ใส่ครบทุกช้อย (ช้อยที่ไม่แก้คัดลอกข้อความเดิม) แก้เฉพาะช้อยที่ < 110
4. แพตช์ชั้นบนสุด `parts/explain/<DIR>/zz<ชุด>_NN.json` (ชื่อเรียงหลัง zq จึงทับเฉพาะช่องที่เขียน) · json.dump(ensure_ascii=False, indent=1)
5. `python3 kit78/gate78.py <dump.json> <แพตช์>` → **OK 0** · รายงาน ≤ 6 บรรทัด (ไฟล์ · OK · ข้อเท็จจริงผิดในเฉลยเดิมที่พบ)

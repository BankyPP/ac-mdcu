# BRIEF (ส่งให้ subagent): เขียนเฉลยข้อสอบเก่าให้ลึกระดับ Subspe ปี 78 — ใช้ได้ทุกวอร์ด
ผู้ใช้ (นศพ. ปี 4) ต้องการเฉลยทุกข้อ "เป๊ะ ๆ 100%" แบบ Subspe 78 / Gen Sx — เคยผิดหวังมากเพราะเฉลยบาง ห้ามบาง
ห้ามแตะ git / ship / ไฟล์อื่นนอกจากไฟล์ของ batch ตัวเอง · เขียนไฟล์ด้วย bash heredoc เท่านั้น (Write tool เคยตัดไฟล์กลางสตริง)

## อ่านก่อน (ต้องอ่านจริง)
- `kit78/EXAMPLES.json` — 4 ข้อตัวอย่างระดับที่ต้องการ (Subspe 78B ข้อ 3, 76A ข้อ 1, 66A ข้อ 60, 66A ข้อ 21) ดูความลึก น้ำเสียง โครงสร้างทุกช่อง
- ข้อมูลข้อ: `python3 kit78/pk.py <dump.json> <key> …` (ได้รับ path dump และรายการ key จากผู้สั่ง) · notes = ข้อความที่ถอดจากไฟล์ (ตัวพิมพ์ ลายมือ ไฮไลต์ สไลด์ที่แปะ) = หลักฐานว่าไฟล์เขียนอะไร · KEY = คีย์ในไฟล์

## เขียน
สคริปต์ python (heredoc) ที่ได้ dict `P[key]=dict(interp=…, why=…, wrong=dict(B=…,…), trap=…, summary=[…], opinion=…, mnemonic=…, guide=…, variants=[…])` แล้ว `json.dump(P, open('parts/explain/<DIR>/<ชื่อแพตช์>.json','w'), ensure_ascii=False, indent=1)`
- ทุก key ในรายการ · wrong = ทุกช้อยที่ไม่ใช่คำตอบเว็บ (*) พอดี · ไม่ต้องใส่ notes/kimg/src (มีในข้อแล้ว)
- ตัวหนา `<b>…</b>` · `&lt;` `&gt;` แทน < > ที่ไม่ใช่แท็ก

## มาตรฐานแต่ละช่อง (ไทยปนศัพท์แพทย์อังกฤษ แบบตัวอย่าง) — มัธยฐาน 78: interp 181 · why 504 · wrong ~170/ช้อย · trap 217 · summary 755 · opinion 193 · variants 401
- **interp** (≥120): โจทย์ให้อะไร → เป็นภาวะอะไร → ถามอะไรจริง ต้องใช้หลักอะไร
- **why** (≥350 · เป้า ~500) ย่อหน้าเดียว: พยาธิกลไก เกณฑ์ ตัวเลข ขั้นตอน guideline ที่ข้อนั้นต้องรู้ ตัวหนาคำสำคัญ · **จบด้วยสิ่งที่ไฟล์เขียน** เช่น `· ตรงคีย์ในไฟล์ วง B พร้อมจด <b>"…"</b>` (ยกจาก KEY/notes ห้ามแต่ง) · ไม่มีลายมือ → อ้างเฉลยในไฟล์ `ไฟล์เฉลยอย่างย่อตอบ B`
- **wrong** (ช้อยละ ≥110): ช้อยนั้นคืออะไร ถูกส่วนไหน ทำไมไม่ใช่ข้อนี้ (ความรู้จริงของช้อยนั้น) → `จะถูกถ้าเป็น…` **ผู้ป่วยจริงอีกราย** (อายุ เพศ อาการ ผลตรวจ) ที่ช้อยนั้นเป็นคำตอบของคำถามเดียวกัน · เป็นไปไม่ได้ (นิยาม/ค่าคงที่/คำถามล็อกชนิด) → `ไม่มีสถานการณ์ใดที่… เพราะ…` · ข้อ except/not: ช้อยที่เป็นข้อความจริง → `ข้อความถูก: …`
- **trap** (≥130): ทำไมคนเลือกผิด + วิธีแยก
- **summary** 6–7 bullet (รวม ≥550 · เป้า ~750): bullet แรก = แกนของคำถาม · ประโยคความรู้แน่น ๆ มีตัวเลข/เกณฑ์ ~90–130 ตัวต่อ bullet ครอบทั้งเรื่องของข้อนั้น
- **opinion** (≥120 · เป้า ~190): `เห็นด้วยกับคำตอบ X ความมั่นใจสูง/ปานกลาง — …` เหตุผล + อ้างคีย์ในไฟล์ + guideline ปัจจุบัน (ชื่อ + ปี) ที่ต่างจากคีย์ · **ถ้าคำตอบเว็บ ≠ คีย์/ลายมือ ต้องมีคำว่า "คีย์" และอธิบาย** · คิดว่าคำตอบเว็บผิด → `ไม่เห็นด้วย…` (ห้ามเปลี่ยนคำตอบเอง) แล้วรายงาน
- **mnemonic** บรรทัดเดียว ตัวหนาทั้งบรรทัด เช่น `<b>Amsterdam 3-2-1-0</b> = 3 ญาติ, 2 รุ่น, 1 คนอายุ &lt;50, 0 FAP`
- **guide** แหล่งจริงมีชื่อ/ปี (guideline ล่าสุดหรือ textbook ฉบับล่าสุด เช่น ACOG PB, RCOG GTG, FIGO, WHO, NCCN, Williams Obstetrics 26e 2022, Berek & Novak 16e 2019, Sabiston 21e 2022, Nelson 22e 2024, Harrison 21e 2022) ห้ามแต่งแหล่ง
- **variants** 4 ข้อ (รวม ≥300 · เป้า ~400): "สถานการณ์ใหม่ → คำตอบ" ยืนเดี่ยวได้ ห้ามซ้ำ summary/จะถูกถ้า
- ข้อเท็จจริงถูกตาม guideline ปัจจุบัน · ไม่แน่ใจตัวเลข → เขียนเป็นหลักการ · แต่ละข้อเขียนเฉพาะ ห้ามก๊อปข้ามข้อ
- **ห้ามคำ:** "นอกสไลด์" · "ถ้าโจทย์" · "จะถูกถ้าคำถาม…" · "ดูข้อ <เลข>" · "ผู้ป่วยรายนี้"/"คนไข้รายนี้" (จำเป็น → `ผู้ป่วยราย&#8203;นี้`) · ชื่อนักศึกษา/ผู้โพสต์/ชื่อผู้ป่วย/HN · ห้ามแก้โจทย์/ช้อย

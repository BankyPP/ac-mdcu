# ฟีเจอร์ทั้งหมดของ platform (ทุกอย่างอยู่ในโค้ดของ kit แล้ว)

แบ่งเป็น 15 หมวด ถ้าเห็นว่ามีอะไรขาด ให้บอก Claude แก้ทั้ง prompt และไฟล์นี้

---

## 1. โครงหน้าเว็บ (ลำดับหน้า)
1. **หน้าเลือกวอร์ด** — หัวข้อ "คลังข้อสอบเก่า" + "เลือกวอร์ดที่กำลังวนอยู่" + การ์ดวอร์ดเรียงตามลำดับใน config (วงกลมชื่อย่อวอร์ด เช่น "Gen Sx Y4" ย่อขนาดตัวอักษรเองถ้าชื่อยาว, ชื่อเต็ม, คำโปรย, จำนวนข้อ หรือ "ยังไม่มีข้อสอบ") + การ์ดบัญชี
2. **หน้า home ของวอร์ด** — ชื่อวอร์ด + ลิงก์ "เปลี่ยนวอร์ด" → แท็บ MCQ / MEQ / OSCE → ปุ่ม Phase 1 / Phase 2 → สถิติ → (ทำต่อรอบค้าง) → (Phase 2: การ์ดทบทวนก่อนสอบ) → ปุ่ม 9 round → การ์ดย้ายความคืบหน้า → "อัปเดตเว็บล่าสุด <วันเวลา build>"
3. หน้าย่อย: เลือกชุด (Service round), ตั้งค่า Grand round, หน้าทำโจทย์, สรุปรอบ, สรุป High-yield, Keyword, บัญชีของฉัน
4. ปุ่ม ⌂ มุมซ้ายบน (กลับ home / กลับหน้าเลือกวอร์ด) และปุ่ม Back ของเบราว์เซอร์ใช้ได้ทุกหน้า (ใช้ลิงก์แบบ `#/<วอร์ด>/<หน้า>`)
5. รีเฟรชหน้าแล้วอยู่หน้าเดิม; Service round จำข้อล่าสุดที่เปิดค้างไว้ (แยกตาม Phase); รอบที่ทำค้างทำต่อได้

## 2. หัวข้อแถบบน (ตั้งใน config)
- หน้าที่ไม่ได้ทำข้อสอบ (home, เลือกชุด, สรุป ฯลฯ): `homeBrand` เช่น **AC Gen Sx Y4 MDCU79 by BankyPP** (ยาวได้ ขึ้น 2 บรรทัดบนจอแคบ ไม่ตัดคำ)
- ตอนทำข้อสอบ: `quizBrand` เช่น **AC Gen Sx Y4 MCQ** (เปลี่ยนเป็น MEQ/OSCE ตามชนิดข้อสอบ)
- หน้าเลือกวอร์ด: "คลังข้อสอบเก่า"
- ชื่อแท็บเบราว์เซอร์ / การ์ด artifact: `title`
- `year` (เช่น Y4) ต่อท้ายชื่อวอร์ดและชื่อย่อทุกวอร์ดอัตโนมัติ — ขึ้นปีใหม่แก้ที่เดียวเป็น Y5

## 3. แท็บ MCQ / MEQ / OSCE
- อยู่บนสุดของหน้า home
- วอร์ดที่ไม่มีสอบชนิดนั้น (`noExam`) → ขึ้น "<วอร์ด> ไม่มีสอบ MEQ" + "วอร์ดนี้สอบเฉพาะ MCQ / OSCE" และซ่อนปุ่ม Phase
- ชนิดที่มีสอบแต่ยังไม่มีข้อ → "ยังไม่มีข้อสอบ <ชนิด> ในวอร์ดนี้"
- ตอนนี้ระบบทำโจทย์รองรับ MCQ (MEQ/OSCE เป็นช่องรอเพิ่มทีหลัง)

## 4. Phase 1 / Phase 2
- ปุ่มสลับ + คำอธิบายสีเทาใต้ปุ่ม
  - Phase 1 ช่วงเรียน: เก็บความรู้ไปใช้บนวอร์ด / ดูแนวข้อสอบ / เนื้อหาในสไลด์-นอกสไลด์
  - Phase 2 ช่วงใกล้สอบ: ทวนข้อสอบเก่ารอบสอง
- ข้อสอบชุดเดียวกันเป๊ะ แต่ **ความคืบหน้าแยกกัน** (กระดาษคำตอบของ Phase 2 เริ่มใหม่ แต่ยังรู้ว่าข้อไหนเคยทำ/ผิดใน Phase 1)
- สถิติใต้ปุ่ม: คลังมี N ข้อ · Phase นี้ทำแล้ว · ล่าสุดถูก %

## 5. ปุ่ม 9 round (ชื่อ + คำอธิบายสีเทา, เลข 01–09)
| # | Round | การทำงาน |

| 01 | Grand round | สุ่มจากทั้งคลัง เลือกจำนวน 10/20/40/60/ทั้งหมด + ติ๊ก "เฉพาะข้อที่ยังไม่เคยทำใน Phase นี้" → ทำเป็นรอบ |
| 02 | Service round | หน้าเลือกปี/rotation (ชิปแยกตามปี แสดง ทำแล้ว/ทั้งหมด, เลือกได้หลายชุด, ไม่เลือก = ทุกชุด) → ทำแบบกระดาษคำตอบ |
| 03 | Morning round | "เร็ว ๆ นี้" (รอกำหนด) |
| 04 | Legendary round | "เร็ว ๆ นี้" |
| 05 | Ward staff round | เฉพาะข้อที่เคยทำแล้วใน Phase นี้ และคำตอบล่าสุดถูกติดกันไม่ถึง 2 ครั้ง (ถูกครั้งเดียว / ล่าสุดผิด / ผิดแล้วถูกครั้งเดียว — ไม่สนว่าก่อนผิดเคยถูก) มีป้ายตัวเลขจำนวนข้อ |

- รอบที่ค้าง (Grand / Ward staff / Phase 2 tools) มีปุ่ม "ทำต่อ: <ชื่อรอบ> ทำไป x/N" บนหน้า home

## 6. หน้าทำโจทย์ (เหมือน platform เดิมทุกอย่าง)
- โทนกระดาษคำตอบ OMR: ตัวเลือกวงกลม A–E, ฟอนต์ Chakra Petch (ตัวเลข/หัว) + IBM Plex Sans Thai (เนื้อหา), สีชมพู-แดงเข้ม #C2386A บนพื้นเทาเขียวอ่อน
- เลขข้อตัวใหญ่ + ป้าย "ปี" (MDCU77) + "Rotation" (RoA) + ปุ่ม **⚑ ไม่มั่นใจ** (กดติด/เอาออก)
- ในรอบ (Grand/Ward staff/…) มีบรรทัด "<ชื่อรอบ> · ข้อ i/N · Phase X" เหนือเลขข้อ
- โจทย์อังกฤษ → รูปโจทย์ (ถ้ามี, มีคำบรรยายใต้รูป) หรือกล่องเส้นประ 🖼 บรรยายรูปที่ไม่มีในไฟล์ → ข้อความต้นฉบับสีเทา (ส่วนก่อน " — ")
- เลือกช้อย → "ยืนยันคำตอบ" (หรือ A–E / 1–5 แล้ว Enter) → ล็อก, ช้อยถูกสีเขียว + วงแหวนเขียว, ช้อยที่ตอบผิดแดงขีดฆ่า, ช้อยอื่นจาง → เลื่อนลงไปที่เฉลยเอง
- **ช่อง "✎ ทด / จดก่อนตอบ"** (พับได้) ใต้ปุ่มยืนยัน — พิมพ์หรือเขียนด้วยนิ้ว/ปากกา; แยกตาม Phase (Phase 2 ไม่เห็นที่ทดของ Phase 1)
- แถบล่างค้าง: ข้อก่อน · i / N · ข้อถัดไป (คีย์ ←/→); ในรอบ ข้อสุดท้ายปุ่มเปลี่ยนเป็น "ดูสรุปรอบนี้"
- ข้อก่อน/ถัดไปวนเฉพาะในชุด/ตัวกรองที่เลือก

## 7. เฉลย (เรียงตามนี้)
1. ถูก/ผิด + "คุณตอบ X · เฉลย Y. <ช้อย>"
2. ป้าย: "repeated xN", ปุ่ม "ทำข้อนี้ใหม่", "ไฟล์ <ชื่อไฟล์> หน้า p (โจทย์) + <ไฟล์เฉลย> หน้า q (เฉลย) · ข้อ n ในต้นฉบับ", กล่องฟ้า 📘 อ้างอิง guideline, ป้ายเหลือง "⚠ คีย์ไม่ชัวร์ / โจทย์ต้นฉบับไม่ครบ", "คีย์ในไฟล์: …", "ส่วนที่เหลือของโจทย์ต้นฉบับ: …" (ส่วนหลัง " — ")
3. ตีความโจทย์
4. ทำไม X ถูก
5. ทำไมข้ออื่นผิด (วงกลมตัวอักษร ครบ 4 ข้อ)
6. ระวังกับดัก (ขีดแดงซ้าย)
7. สรุปความรู้จากข้อนี้
8. สิ่งที่เขียนไว้ในไฟล์ (ไฮไลต์เหลือง, ฝังรูปด้วย {{IMG:key}})
9. สไลด์/รูปอ้างอิงจากไฟล์เฉลย
10. ช่วยจำ
11. ความเห็นของผม (กล่องเหลือง)
12. โจทย์แบบใหม่ที่อาจออก
13. **สรุปของฉันจากข้อนี้** (กล่องชมพู) — พิมพ์/เขียนด้วยมือ บันทึกอัตโนมัติ ใช้ร่วมทั้ง 2 Phase
14. **ถาม Claude เพิ่มเติม** — ปุ่มคำถามสำเร็จรูป 4 อัน + ช่องพิมพ์ → "เปิดใน Claude ↗" (แนบโจทย์ ตัวเลือก เฉลย คำตอบของเรา guideline คำอธิบาย + กติกาให้ตอบตามหลักฐาน ห้ามแต่งข้อมูล) และคัดลอกข้อความไว้ให้วางเองถ้าลิงก์ไม่ขึ้น
15. "✎ ที่ทดไว้ก่อนตอบ" (พับไว้ ถ้ามี)
- "ดูข้อ 123" ในเนื้อหาอ้างแบบ rid → แอปแปลงเป็นเลขข้อที่แสดงเอง

## 8. โน้ต (พิมพ์ + เขียนด้วยมือ)
- แท็บ ⌨ พิมพ์ / ✍ เขียน (จุดสีบอกว่าแท็บไหนมีเนื้อหา), จำว่าชอบใช้แบบไหน
- พิมพ์: ช่องขยายตามข้อความ, "บันทึกแล้ว" อัตโนมัติ
- เขียน: กระดาษมีเส้น, ปากกา/ยางลบ (ลบทั้งเส้น), สีดำ/แดง/น้ำเงิน, ↶ ย้อน, ＋ พื้นที่ (ขยายลง), ล้าง; รองรับนิ้ว, Apple Pencil (กันฝ่ามือ: ถ้าใช้ปากกาแล้วนิ้วจะไม่ขีด), เมาส์; ปรับตามความกว้างจอ; dark mode ใช้สีตามธีม

## 9. กระดาษคำตอบ (แผงข้าง, ปุ่ม "กระดาษคำตอบ x/N" มุมขวาบนตอนทำโจทย์)
- Service round: หัว "กระดาษคำตอบ · Phase X", สถิติ ทำแล้ว / ถูก / ความแม่น % ของชุดที่เลือก
- แถบเลือกชุด slider แนวนอนแถวเดียว (ปัดได้, ล้อเมาส์ได้, ชื่อย่อ "77 RoA") เลือกหลายชุดพร้อมกัน, "ทุกชุด (เลือก N)"
- ตัวกรอง: ทั้งหมด / ยังไม่ทำ / ตอบผิด / ไม่มั่นใจ (+ Phase 2: ตอบถูก / ไม่เคยทำใน P1)
- รายการข้อเป็นวงกลม A–E (เขียว=ตอบถูก แดง=ตอบผิด วงขอบเขียว=เฉลย) + ⚑ + (Phase 2: P1✓/P1✗) แตะเพื่อไปข้อนั้น
- ลิงก์ด้านล่าง: ทำข้อที่ผิดใหม่ (เปิดเฉพาะข้อผิดให้ทำใหม่ + สลับไป "ยังไม่ทำ"), ส่งลิงก์ความคืบหน้า, นำเข้า, ล้างกระดาษคำตอบ (มีหน้าต่างยืนยัน, ประวัติการตอบยังอยู่)
- ข้อความสถานะบันทึก (☁️ / 💾 / ⚠️)
- ในรอบ: แสดงข้อในรอบ, ตัวกรอง ทั้งหมด/ยังไม่ทำ/ตอบผิด, ปุ่ม "จบรอบ ดูสรุป"
- Esc ปิดแผง

## 10. สรุปรอบ
- คะแนนตัวใหญ่ x / N, ถูก / ผิด / ยังไม่ได้ตอบ / ความแม่น %
- ปุ่ม: ทำข้อที่ผิดในรอบนี้อีกครั้ง, กลับไปทำข้อที่ข้ามไว้, กลับหน้าหลัก
- รายการข้อแบบกระดาษคำตอบ แตะเพื่อกลับไปดูข้อนั้น

## 11. Phase 2 — การ์ด "ทบทวนก่อนสอบ"
- 📘 สรุป High-yield — หัวข้อที่เคยออก (Claude เขียนจากข้อสอบทุกปี + lecture) พร้อมปุ่มเลขข้อกดเปิดข้อนั้น; ตอนยังไม่เขียน จะแสดง "สรุปความรู้" ของทุกข้อแยกตามชุด
- 🔑 Keyword ตอบข้อสอบ — ตาราง "เจอคำว่า → นึกถึง/ตอบ" + เลขข้อ; ตอนยังไม่เขียน แสดง "ช่วยจำ" ของทุกข้อ
- ✗ ข้อที่ยังผิดอยู่ · ✓ ข้อที่ทำถูกแล้ว · ⚑ ข้อที่ยังไม่มั่นใจ · ○ ไม่เคยทำใน Phase 1 (มีตัวเลขจำนวน, กดแล้วทำเป็นรอบ) — "ยังผิด/ถูกแล้ว" ดูจากคำตอบล่าสุดของทั้ง 2 Phase

## 12. การบันทึกความคืบหน้า
- เก็บ **ประวัติการตอบทุกครั้ง** ต่อข้อ ต่อ Phase (ใช้กับ Ward staff round), ⚑, โน้ต, ลายมือ, ชุดที่เลือก, ข้อล่าสุดที่เปิด, รอบที่ค้าง
- ผูกกับ "ตัวข้อ" (uid) ไม่ใช่เลขข้อ → เพิ่มชุดใหม่/เรียงใหม่แล้วไม่หาย
- เก็บในเครื่องอัตโนมัติเสมอ
- **ใน artifact ของ Claude:** ซิงก์เข้าบัญชี Claude ของคนที่เปิดอัตโนมัติ (ไม่ต้องสมัคร) → ใช้ได้ทุกเครื่องที่ล็อกอิน Claude บัญชีเดียวกัน; ปุ่ม ☁️ มุมขวาบน, "☁️ บันทึกในบัญชี Claude แล้ว"; แต่ละคนเห็นแค่ของตัวเอง; ถ้าพักแอป บันทึกทันที
- **บนเว็บของตัวเอง (ถ้าย้ายไป GitHub Pages ฯลฯ):** ปุ่ม 👤 → สมัคร/เข้าสู่ระบบด้วย Google, อีเมล หรือ **ชื่อผู้ใช้ + รหัสผ่าน** (ใช้ได้เมื่อใส่ Firebase config), ออกจากระบบเลือกลบข้อมูลจากเครื่องได้, ความคืบหน้าในเครื่องรวมเข้าบัญชีเอง; ไม่ล็อกอินก็ใช้ได้
- แต่ละวอร์ดเก็บแยกกัน; แต่ละ platform (storageKey) แยกกัน

## 13. ย้ายความคืบหน้า (การ์ดท้ายหน้า home + ในกระดาษคำตอบ)
- 🔗 **ส่งลิงก์ความคืบหน้า** — ทุกวอร์ด ทุก Phase (ประวัติ 20 ครั้งล่าสุด/ข้อ/Phase) + ⚑, บนมือถือเปิดเมนูแชร์; ใน artifact เป็น **รหัส** `AC-PROGRESS:…` ให้คัดลอก (เพราะ artifact ไม่มีลิงก์ของตัวเอง)
- ⤵ **นำเข้าลิงก์ / รหัส** — รวมกับของเครื่องนี้ (ข้อไหนเครื่องนี้ทำมากกว่าเก็บของเครื่องนี้); รับรหัส/ลิงก์รูปแบบเก่าได้
- 💾 **ดาวน์โหลดไฟล์สำรอง** (.json) — ครบทุกอย่างรวมโน้ตและลายมือ
- 📂 **นำเข้าไฟล์สำรอง**
- เปิดลิงก์ความคืบหน้า → ถามก่อนนำเข้า

## 14. ใช้งานบนมือถือ / การเข้าถึง
- safe-area ขอบจอ iPhone, ปุ่มใหญ่, แถบล่างค้าง, ไม่มี text autosizing (ตัวหนังสือขนาดคงที่)
- dark mode อัตโนมัติตามเครื่อง
- ลดการเคลื่อนไหวถ้าเครื่องตั้งไว้

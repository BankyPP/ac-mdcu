3.2หน้าเฉลย — เรียงจากบนลงล่าง

  1. 1ผลถูก / ผิด — "คุณตอบ X · เฉลย Y"
  2. 2ป้าย — repeated ×N (ข้อนี้ออกซ้ำ) · ไฟล์และหน้าต้นฉบับ · ปุ่ม "ทำข้อนี้ใหม่" · ที่มา (ใน Legendary/Morning)
  3. 3📘 guideline ที่เกี่ยวข้อง (กล่องฟ้า)
  4. 4⚠ คีย์ไม่ชัวร์ / โจทย์ไม่ครบ (ป้ายเหลือง ถ้ามี)
  5. 5ตีความโจทย์ — โจทย์ถามอะไรจริง ๆ
  6. 6ทำไมข้อนี้ถูก
  7. 7ทำไมข้ออื่นผิด ทีละตัวเลือก
  8. 8ระวังกับดัก
  1. 9สรุปความรู้จากข้อนี้ — ครบในตัว ไม่ต้องไปเปิดข้ออื่น
  2. 10สิ่งที่เขียนไว้ในไฟล์ + รูปที่ตัดมาจากไฟล์เฉลย / สไลด์ · R และ T ที่เกี่ยวข้อง (แนบเฉพาะเมื่อคำในโจทย์/คำตอบตรงกับไฟล์นั้นจริง)
  3. 11ช่วยจำ
  4. 12ความเห็นของผม (กล่องเหลือง — มีทุกข้อ)
  5. 13โจทย์แบบใหม่ที่อาจออก
  6. 14สรุปของฉันจากข้อนี้ — พิมพ์ / เขียนมือ ใช้ร่วม 2 Phase
  7. 15ถาม Claude เพิ่มเติม — ปุ่มคำถามสำเร็จรูป หรือพิมพ์เอง
  8. 16✎ ที่ทดไว้ก่อนตอบ (พับไว้)

ข้อจาก Unit round มีภาพสไลด์ที่อ้างอิงแนบในเฉลยด้วย · คีย์ข้อสอบเก่ามาจากที่จดกันมา ไม่ได้ถูก 100% ข้อที่สงสัยจะมีป้าย ⚠ บอก · ข้อสอบเก่าที่ไม่มีเฉลยในไฟล์ เฉลยอ้าง guideline + lecture

กระดาษคำตอบตอนอยู่ใน round อื่น

  • โชว์เฉพาะข้อในรอบนั้น แต่เลือกได้เหมือน Service: ชิปชุด (เฉพาะชุดที่อยู่ในรอบ) · ชิปบท · สถานะ ตอบถูก / ไม่เคยทำใน P1 · ป้าย P1✓/✗
  • กรองแค่สิ่งที่แสดง ลำดับและข้อในรอบไม่เปลี่ยน · รอบใหม่เริ่มที่ "ทั้งหมด"
  • รอบที่เลือก Tag มีแถบ Tag ("เอาออก" = เติมข้อที่เหลือเข้ารอบเดิม)

หน้าสรุปรอบ

  • คะแนนตัวใหญ่ x / N · ถูก · ผิด · ยังไม่ตอบ · %
  • ปุ่ม ทำข้อที่ผิดอีกครั้ง · กลับไปข้อที่ข้าม · กลับหน้าหลัก
  • ปุ่ม จบรอบ ดูสรุป กดได้ตลอด
💡 ทำครบชุดแล้ว กดตัวกรอง ตอบผิด แล้วไล่ทวนเฉพาะข้อแดง เร็วที่สุด

3.4MEQ และ OSCE ทำต่างจาก MCQ ตรงไหน

MEQ
  • เป็นเคสแบ่ง Part แต่ละ Part มีข้อย่อย พิมพ์ตอบเอง · บางวอร์ดแยก Case กับ Short answer
  • มีนาฬิกาจับเวลาแบบนับขึ้นทุกข้อ
  • ส่งคำตอบแล้วเห็นเฉลยแบบ checklist: หัวข้อใหญ่ + สิ่งที่ต้องมี คิดคะแนนเป็นสัดส่วน
  • ข้อ must not miss พลาดแล้วข้อย่อยนั้นได้ 0 (แก้คะแนนเองได้)
  • ให้คะแนนตัวเอง หรือกด ตรวจด้วย AI AI ให้ช่วยแนะนำคะแนน
OSCE
  • เปิดทีละสถานี ข้อย่อยขึ้นพร้อมกัน
  • ไอคอนสถานี: 📝 ไม่มีอาจารย์ · 👨‍⚕️ มีอาจารย์ · 🩺 หัตถการ
  • เฉลยเป็น checklist แบบ OSCE ติ๊กอัตโนมัติจากคำสำคัญที่พิมพ์ (แก้ได้) หรือให้ AI ช่วยตรวจ
  • คะแนนข้อย่อย = สัดส่วน checklist × คะแนนเต็ม · ผลเป็น %
  • บางรอบมีโหมด IRL (มีคนคุมจริง จอโชว์แค่โจทย์ ผู้คุมดูบท SP + checklist) กับ SIM (พิมพ์สิ่งที่จะพูด/ทำ)

คีย์ MEQ / OSCE ก็ไม่ได้ถูก 100% เหมือน MCQ — ในเฉลยจะมีกล่องเหลืองเตือนไว้ · ชื่อสถานีและข้อความ recall ไม่บอกคำตอบ (recall โชว์หลังส่งคำตอบ)

3.5รูปในสถานี OSCE — 🔎 ค้นรูป / ใส่รูปเอง ใหม่

สถานีที่โจทย์ต้องดูรูป (CXR, blood smear, EKG, รูปผื่น ฯลฯ) แต่ในคลังไม่มีรูปจริง — เช่น ข้อสอบเก่าที่ไฟล์ไม่มีรูป หรือสถานีที่ AI แต่ง — จะมีส่วนพับใต้โจทย์ให้หารูปมาใส่เอง

ทุกเรื่องที่เคยออก แยกตามหัวข้อ พร้อมปุ่มเลขข้อกดไปทำได้ — มีป้าย 🆕 + ตัวเลข เมื่อมีข้อใหม่ที่ยังไม่อยู่ในสรุป
🔑 Keyword ตอบข้อสอบ
ตาราง "เจอคำว่า → นึกถึง / ตอบ" พร้อมเลขข้อ (5.5)
รายการข้อ
✗ ยังผิดอยู่ · ✓ ทำถูกแล้ว · ⚑ ยังไม่มั่นใจ · ○ ไม่เคยทำใน P1 · 📝 มีโน้ต — กดแล้วทำเป็นรอบ

"ยังผิด / ถูกแล้ว" ดูจากคำตอบล่าสุดของทั้ง 2 Phase · ตัวเลขบนแต่ละอันคือจำนวนข้อ · แตะหัวการ์ดเพื่อพับ/กาง

5.2สรุป High-yield — โครงหน้าและวิธีอ่าน

  1. 1หัวหน้า คำอธิบาย + คำอธิบายสีปุ่ม + เปิดทั้งหมด / ปิดทั้งหมด (ปิดทั้งหมดไม่ปิดกล่อง 🔥)
  2. 2🔥 เรื่องที่ออกบ่อยที่สุด (top 15) เปิดไว้เสมอ แต่ละบรรทัดบอก หัวข้อ · ระดับ · ออกกี่ rotation · กี่ข้อ · ทำแล้วเท่าไหร่ · ไม่แม่นกี่ข้อ — แตะชื่อเพื่อกระโดดไปเรื่องนั้น
  3. 3หัวข้อ (Tag) ▸ กดเปิด → ข้างในแบ่งเป็นกลุ่ม → แต่ละกลุ่มมีหลายเรื่อง
  4. 4เปิดเรื่อง จะเห็น 📈 เคยออกกี่ rotation ปีไหนบ้างและแนวโน้ม · แนวคำถามที่เคยออก · Pattern การตอบ / high yield · ระวัง / กับดัก · ข้อที่เคยออก (ปุ่มเลขข้อ)
  5. 5จำให้ ว่าเปิดอะไรไว้และเลื่อนถึงไหน — แตะเลขข้อไปทำแล้วกด Back กลับมาที่เดิม
ℹ️ นับอะไรบ้าง นับเฉพาะข้อสอบเก่า (ข้อใน Service round) ไม่นับ Unit / Admission / โจทย์ AI · ตัวเลขคำนวณใหม่ทุกครั้งที่เปิด · ทุกครั้งที่เพิ่มข้อสอบเก่า สรุปของวอร์ดนั้นถูกอัปเดตตาม

ทุกเรื่องมี flow สิ่งที่ต้องทำตามลำดับ (สถานีมีอาจารย์ = checklist) · มี keyword ที่ต้องพูด/เขียนให้ได้

★ วิธีใช้สรุป High-yield ให้คุ้ม

  1. 1เริ่มจากกล่อง 🔥 top 15 — อ่าน Pattern + กับดักของ 15 เรื่องนี้ให้ครบก่อน
  2. 2หาจุดอ่อน — ไล่ดูหัวข้อที่ "ไม่แม่น" เยอะ หรือ "ทำแล้ว" น้อย
  3. 3เปิดเรื่อง → อ่าน 📈 แนวโน้ม ปีล่าสุดยังออกไหม ถ้ายังออก = ต้องแม่น
  4. 4แตะปุ่ม ○ / ✗ ไปทำทันที แล้วกด Back กลับมา ปุ่มจะเปลี่ยนสี
  5. 5ทำจนเรื่องสำคัญเป็น ✓ ทั้งแถว แล้วค่อยไปเรื่องถัดไป
  6. 6คืนก่อนสอบ เปิดแค่ top 15 + ส่วน "ระวัง / กับดัก" ของหัวข้อที่อ่อน

  • หน้า Admit · ICU · Discharge ของวอร์ด: วันเริ่มวอร์ด วันสอบ (หลายวัน/หลายเวลาได้ เรียงให้เอง) · การ์ด "MCQ สอบจริง" และ "OSCE สอบจริง" (จำนวนข้อ + นาที) — ใช้กับนับถอยหลังและ Legendary
  • ถ้ายังไม่ได้ตั้ง Legendary จะบอกให้ตั้งก่อน (หรือบอก Claude ให้ตั้งค่าเริ่มต้นของวอร์ด)

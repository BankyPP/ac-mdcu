## กติการวม (กติกาถาวรของผู้ใช้: ปีเดียวกัน rotation เดียวกัน = ชุดเดียว ไม่แยกตามไฟล์)
1. ดูทุกหน้าของช่วงตัวเองด้วยตา หาเครื่องหมายคีย์ของไฟล์นี้ (วง/ติ๊ก/ไฮไลต์/ลายมือ/ตัวแดง/ส่วนเฉลยท้าย) ก่อน — คีย์ปลอม (มีแต่ "A." หรือช้อยเดียวซ้ำทั้งแถบ) = ไม่มีคีย์
2. **ข้อที่ตรงกับข้อเดิม** (stem+ช้อยเหมือนหรือน่าจะเหมือน แม้ถ้อยคำต่างเล็กน้อยจากการจดคนละคน): แก้ข้อเดิมในที่ — ไม่เพิ่มข้อใหม่
   - `key` เปลี่ยนเป็นคีย์ในไฟล์นี้ `"<อักษร> <ช้อย> (คีย์ในไฟล์ Key 127)"` (ถ้าข้อเดิมมีคีย์อยู่แล้วและตรงกัน คงไว้แล้วต่อท้ายว่า Key 127 ตรงกัน · ถ้าขัดกัน เขียนทั้งสองคีย์)
   - เพิ่ม `kimg` ครอปบริเวณข้อนั้นจาก k127: `python3 parts/simed/crop.py /home/claude/work/k127.pdf <หน้า> <y0> <y1> kk127<r>_<orig ที่ทำเป็นตัวพิมพ์เล็ก a-z0-9_>` (r = a/b/c/d/e ตาม rotation) — ต่อท้าย kimg เดิมถ้ามี
   - **ตรวจคำตอบเดิมเทียบคีย์:** ตรง → ปรับ `opinion` เป็น "เห็นด้วยกับคีย์ ..." · ไม่ตรง → ตัดสินตามแหล่งที่เชื่อถือได้ฉบับล่าสุด: ถ้าคีย์ถูก แก้ `ans` + `why`/`wrong`/`summary` ให้สอดคล้องทั้งข้อ · ถ้าเรายังเห็นต่าง คง ans เดิม ใส่ `flag:"⚠ ..."` + อธิบายใน `opinion` ว่าคีย์ตอบอะไร ทำไมไม่เห็นด้วย
   - ลายมือ/โน้ตในไฟล์นี้ ถอดเพิ่มลง `notes` (บอกว่ามาจาก Key 127) · ข้อความในไฟล์นี้ที่ครบกว่า recall เดิม (ช้อยครบกว่า ค่าแลปเพิ่ม) → ปรับ stem/opts ให้ตรงต้นฉบับมากขึ้นโดยคง ans ให้ถูก และแก้ `gray` ให้รวมต้นฉบับจากทั้งสองไฟล์
   - ห้ามเปลี่ยน `set`, `ro`, `orig` ของข้อเดิม (เป็น key ของ progress ผู้ใช้และแท็ก) · `file`/`page` คงของเดิม
3. **ข้อที่ต่างแม้คำเดียว/รายละเอียดเดียว หรือไม่มีในชุดเดิม** → เพิ่มเป็นข้อใหม่ในไฟล์ข้อมูลเดิมของ rotation นั้น (ต่อท้าย) `file:"SIM127K"`, `page` = หน้าใน k127, `orig:"K<เลขในไฟล์ Key127>"` (ไม่มีเลข `"K ไม่มีเลข <k>"`) — เฉลยละเอียดเท่าข้ออื่น รูปโจทย์ `qk127<r>_<n>` รูปคีย์ `kk127<r>_<n>` · เพิ่มแท็กของข้อใหม่ลง `parts/simed/<code>_tags.json` เดิมของ rotation นั้น (key = orig)
   - Ro405–408: ข้อใหม่ที่ orig ≤ 30 ของไฟล์ Key127 ใส่ `data_b22.js` + `s127b1_tags.json` · ที่เหลือ `data_b23.js` + `s127b2_tags.json`
4. ข้อเดิมที่ไม่มีในไฟล์นี้: ไม่แตะ
5. อัปเดตหัวคอมเมนต์ของไฟล์ข้อมูล: เพิ่มบรรทัด "10 พ.ย. 2026 เติมคีย์จาก Key_127 Summative127 Key หน้า …: ตรงกับข้อเดิม N ข้อ, ข้อใหม่ M ข้อ, วิธีอ่านเครื่องหมายคีย์ …"

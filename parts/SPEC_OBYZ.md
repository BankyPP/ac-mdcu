## โจทย์และช้อย (ต่างจากชุด recall)
- นี่คือ**หนังสือข้อสอบตัวพิมพ์ครบ** → stem/opts = **ข้อความหนังสือตรงตัว** ลำดับช้อยตามหนังสือ (A–E ของเรา = A–E ของหนังสือ) — ห้ามแต่งเติม ห้ามตัดตัวลวง. แก้ได้เฉพาะตัวอักษรเพี้ยนจากการถอด (เช่น "th" ลอยของ 12th, ตัวไทยเพี้ยน (cid:…)) — ดูรูปแล้วเขียนให้ถูก. ถ้าหนังสือพิมพ์ผิดจนความหมายเพี้ยน แก้น้อยที่สุด + ใส่ข้อความเดิมใน `gray` + บอกใน notes.
- ช้อยภาษาไทยในหนังสือ → คงภาษาไทยตามหนังสือ.
- หนังสือมีช้อยไม่ครบ 5 (บางข้อมี 3–4 ช้อย หรือ 1 ช้อย — ตรวจในรูปก่อนว่าถอดตกหรือหนังสือมีแค่นั้นจริง) → เติมช้อยลวงที่สมเหตุสมผลจนครบ 5 ต่อท้าย (ห้ามแย่งคำตอบ) + notes: "หนังสือมีช้อย A–C; D–E เติมเอง". ถ้าหนังสือมีช้อยเดียวจริง (ข้อนิยาม) = ช้อยนั้นคือคำตอบที่ผู้แต่งให้ → เขียนเป็นโจทย์ MCQ ที่สมบูรณ์ + ติด ⚠.
- โจทย์ที่ต้องดูรูปและหนังสือมีรูปพิมพ์อยู่: 42.4 (รูป scalp layers) และ 42.8 (รูปทารก) — ตัวรวมใส่รูปให้; ใน stem เขียนตามหนังสือ. รูปอื่นทั้งหมดในหน้า = ผู้จดแปะเอง (ไม่ใช่โจทย์) → ไปอยู่ใน notes.

## key — พิจารณา 2 เวอร์ชันร่วมกัน
- ดูว่าแต่ละเวอร์ชัน**ตอบอะไร** (วงตัวอักษร / ไฮไลต์ช้อย / ✓ / เขียนคำตอบ / กากบาทช้อยอื่น) แล้วเขียน `key:"ver.1: <ตัวอักษร> <ข้อความช้อย> · ver.2: <ตัวอักษร> <ข้อความช้อย>"`. ถ้าเวอร์ชันไหนไม่ได้ระบุคำตอบ: `ver.2: ไม่ได้ระบุคำตอบ`. ถ้าระบุ 2 ช้อย/ลังเล/แก้คำตอบ ให้เขียนตามที่เห็น เช่น `ver.1: B (ขีดฆ่า C แล้วเปลี่ยนเป็น B)`.
- **คำตอบของเรา (ans) ตัดสินจากหลักฐาน** — เชื่อเวอร์ชันไหนก็ได้ หรือไม่เชื่อทั้งคู่ก็ได้. ติด `flag:"⚠ …"` เมื่อ: 2 เวอร์ชันตอบไม่ตรงกัน / เราตอบต่างจากทั้งคู่หรือจากเวอร์ชันใด / ไม่มีเวอร์ชันไหนระบุคำตอบและตีความได้หลายแบบ / โจทย์กำกวม-ตอบได้ 2 ช้อย / หนังสือมีช้อยไม่ครบ. ใน opinion อธิบายเต็ม: แต่ละเวอร์ชันตอบอะไร เราเลือกอะไร เพราะอะไร ความมั่นใจ.
- ถ้า 2 เวอร์ชันตอบตรงกันและถูก → ไม่ต้อง flag; opinion สั้น ๆ ได้.

## notes — ถอดทุกอย่างที่จดไว้ จาก**ทั้ง 2 ไฟล์ แยกบอกว่ามาจากไฟล์ไหน**
รูปแบบ: `"<b>ver.1:</b> …<br><b>ver.2:</b> …<br>…"` — ถอดลายมือ (ไทย/อังกฤษ ตรงตัวที่สุด), คำที่ไฮไลต์/ขีดเส้นใต้/วงไว้ในโจทย์ (บอกว่าเน้นคำไหน), ตาราง/สไลด์/รูปที่แปะไว้ (สรุปเนื้อหาในรูปเป็นข้อความสั้น ๆ + "(ดูรูป ver.1/ver.2 ด้านล่าง)"), สัญลักษณ์ (★, ?, ✓, "ซ้ำ", "ตรงแอค" ฯลฯ).
- **ข้อมูลที่จดไว้แล้วผิด/คลาดเคลื่อน → บอกทันทีต่อจากบรรทัดนั้น**: `✎ <b>น่าจะผิด:</b> … ที่ถูกคือ … (อ้างอิง)`.
- เวอร์ชันไหนไม่ได้จดอะไรเลยในข้อนั้น → `<b>ver.2:</b> ไม่ได้จดอะไรเพิ่ม (วงคำตอบ X อย่างเดียว)` หรือ `ไม่ได้จดอะไร`.
- ปิดท้าย notes ด้วยการแก้ไขที่เราทำกับโจทย์/ช้อย (ถ้ามี) และบรรทัด "ลายมือบนสุดของหน้า …" ถ้าย้ายมาจากข้อก่อน.
- ข้อที่ลายมืออ่านไม่ออก → เขียน "[อ่านไม่ออก]" ห้ามเดา.

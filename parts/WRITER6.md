# งานผู้เขียนข้อสอบ — ชุด MCQ MDCU69–65 (Gen Sx + Subspe Sx) (16 พ.ย. 2026)

ใช้ `parts/WRITER3.md` ทั้งหมด (ข้อ 1–8) โดยแทนชื่อชุดเป็นชุดที่ได้รับ — SPEC: `parts/SPEC<ชุด>.md` (เช่น `parts/SPEC67A.md`, `parts/SPECS67A.md`), checker: `parts/check_<code>.js`, ไฟล์ part: `parts/<code>_partN.js` (code ตามตารางใน `parts/ANALYST6.md`: a69, c69, a68 …, sa67 …)
- ตัวอย่างระดับความละเอียด: ชุดไฟล์ A เดียวกันที่ทำเสร็จแล้ว `data/data_b21.js` (72A) และ `data/data_b28.js` (70C) — ดู 2–3 ข้อก่อนเขียน
- ช่องแหล่งที่มา (file/page/page2 และสำหรับข้อที่มีทั้งสองไฟล์ `file2`/`page3`/`orig2`) และ KS (`KSA` / `KSB` / `KSAB` — ค่าคงที่ที่ตัวประกอบไฟล์มีให้) ทำตามที่ SPEC ระบุทีละข้อ
- ข้อที่รวมจาก 2 ไฟล์: notes บอกว่าแต่ละไฟล์จดต่างกันอย่างไร และแต่ละไฟล์ตอบอะไร
- **ห้ามแก้ SPEC หรือไฟล์ part ของคนอื่น** — เขียนเฉพาะ part ที่ได้รับ
- ข้อที่ไฟล์เขียน "จำ" → ทำตามส่วน "⭐ ข้อที่ไฟล์เขียน จำ" ใน `parts/WRITER4.md`
- โจทย์/ช้อยที่แต่งเพิ่ม (recall ไม่ครบ) ต้อง case-based อังกฤษ formal แบบข้อสอบจริง และ notes บอกว่าต้นฉบับจดมาแค่ไหน แต่งอะไรเพิ่ม · ข้อที่ไฟล์ไม่มีคีย์: เฉลยโดยยึด guideline + ตำราฉบับล่าสุด
- ห้ามคัดลอกชื่อคน/HN/ชื่อเฟซบุ๊กลงข้อมูล

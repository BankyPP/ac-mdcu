# งานอัปเดต "สรุป High-yield" Gen Sx MCQ หลังเพิ่มชุด MDCU70 RoA/RoB/RoC, MDCU71 RoA/RoB, MDCU72 RoA/RoB/RoC (25 ต.ค. 2026)

อ่าน `parts/SUMMARY_HY_BRIEF.md` ทั้งไฟล์ก่อน (กติกา รูปแบบ ภาษา ข้อห้าม) — งานนี้เป็นการ **อัปเดตไฟล์เดิม** ไม่ใช่เขียนใหม่

สำหรับแต่ละ tag ที่ได้รับ:
1. `node tools/sumcheck.js data MCQ "<tag>"` → ดูรายการข้อใหม่ที่ยังไม่อยู่ใน section ใด (ข้อ MDCU70|…, MDCU71|…, MDCU72|… ทั้งหมด)
2. `node tools/sumdump.js data MCQ "<tag>"` แล้วอ่านข้อ MDCU70–72 ทุกข้อของ tag นั้นให้ครบ (โจทย์ ช้อย คำตอบ ⚠) — คำตอบของคลัง = คำตอบที่แก้แล้ว ใช้ตามนั้น
3. แก้ไฟล์ `data/sum_mcq_<slug>.js` เดิม:
   - ข้อที่เข้ากับ theme เดิม → เพิ่ม key ใน `members` ของ section นั้น และถ้าข้อใหม่ถามมุมใหม่/ข้อเท็จจริงใหม่ ให้เพิ่มบรรทัดใน `asked` / `pattern` / `pearls` (เช่น ที่คีย์ในไฟล์ผิดแล้วคลังแก้)
   - ข้อที่ถามเรื่องที่ยังไม่มี theme → เพิ่ม section ใหม่ในกลุ่มที่เหมาะ (หรือกลุ่มใหม่) ตามรูปแบบเดิม
   - เรียงกลุ่ม/section ใหม่ถ้าความถี่เปลี่ยน (นับจำนวน rotation ที่ออก) และปรับ `intro` ถ้าแนวหลักของหมวดเปลี่ยน
   - **ห้ามลบ member/เนื้อหาเดิม** ที่ยังถูกต้อง; ห้ามแตะไฟล์ tag อื่น
4. `node tools/sumcheck.js data MCQ "<tag>"` ต้องจบด้วย `bad 0`

ห้ามรัน build / git / แก้ไฟล์อื่น
ตอบกลับสั้น ๆ: ต่อ tag — บรรทัดผล check, ข้อใหม่ไปอยู่ section ไหน (หรือ section ใหม่ชื่ออะไร), ข้อที่ดู mis-tag หรือคำตอบที่สงสัย (key + เหตุผล)

## ขั้นตอน
1. ทำงานในโฟลเดอร์ทำงานที่ได้รับ (มีไฟล์ PDF + t.txt ที่ดึงข้อความไว้แล้ว — ข้อความอาจเพี้ยน/สลับบรรทัด ให้ยึดภาพ). render ทุกหน้าเป็นรูป (`pdftoppm -r 110 -png`) แล้ว **ดูทุกหน้าด้วย Read** (ลายมือ, เครื่องหมาย X/วง/ติ๊ก, สไลด์ที่แปะ, รูปในโจทย์) ห้ามข้ามหน้า. ใช้ `pdftotext -bbox` หา y ของเลขข้อได้
2. รูปในโจทย์ (รูปที่ข้อสอบให้มา) → ครอปจากหน้าที่ render 200 dpi บันทึก `/home/claude/sx-mcq/img/q<prefix>_<n>.jpg` (กว้างไม่เกิน ~700px, JPEG quality ~72); ในตารางระบุ `img:QI(n)` + คำบรรยายรูปสั้น ๆ ที่**ไม่บอกคำตอบ**
3. ไฟล์เฉลยที่มีลายมือ/สไลด์/ตาราง → ครอปบริเวณเฉลยของแต่ละข้อ (ต่อหลายช่วงในแนวตั้งได้) บันทึก `/home/claude/sx-mcq/img/k<prefix>_<n>.jpg` กว้าง 760px JPEG quality ~64 (ตัวอย่างสคริปต์: `/tmp/claude-0/k76c_crop.py`). ถ้าไฟล์เฉลยเป็นตารางข้อความล้วน (ข้อ / คำตอบ / คำอธิบาย) ไม่ต้องครอป — ถอดคำอธิบายลงช่องโน้ตแทน; ถ้าบางข้อในตารางมีรูป/สไลด์แปะ ให้ครอปเฉพาะข้อนั้น
4. ตัดสินคำตอบทุกข้อ: ใช้คีย์เป็นหลัก ถ้าคีย์ขัดหลักฐาน/guideline ล่าสุด → ตอบตามหลักฐาน + ⚠ อธิบาย (ถ้ายังถกเถียงได้ คงคีย์ + ⚠ อธิบาย); ไม่มีคีย์ → เฉลยเอง (`key:NK`) ระบุในตาราง; คีย์บอก 2 ข้อ/มี ?? → ตัดสินเอง + ⚠
5. **ความสอดคล้องทั้งคลัง**: ข้อเรื่องเดียวกับชุดที่มีอยู่แล้วต้องตอบให้สอดคล้อง — ค้นด้วย `cd /home/claude/sx-mcq && DIR=data node tools/find.js "<regex>"` (คลังมี MDCU76 RoA (data_b1.js) และ RoC (data_b2.js)) เช่น achalasia → EGD ก่อน, subepithelial tumor/GIST → EUS, AAA เกณฑ์ผ่า ≥5.5 ชาย/≥5.0 หญิง (ESVS 2024), Child/BCLC, ฯลฯ — ระบุในตารางว่า "สอดคล้องกับข้อ … ของชุด 76A/76C" (เขียนเป็นข้อความ ไม่ใช้รูป "ข้อ N" เพราะสงวนไว้)
6. ข้อที่ออกซ้ำภายในชุด (เช่น คีย์เขียน "ซ้ำข้อ 4") ให้ใส่เป็นข้อแยก (ไม่รวม) และตอบเหมือนกัน
7. ช้อยต้นฉบับไม่ครบ 5 → แต่งเพิ่มให้ครบ 5 โดยตัวลวงต้องไม่ถูกด้วย (ห้ามแต่งช้อยที่แข่งกับคำตอบ); ช้อยที่เป็นภาษาไทยให้แปลอังกฤษ; ห้ามวงเล็บ / " / " / " — " / " - " / "e.g."; ช้อยถูกไม่ยาวกว่าตัวลวงที่ยาวสุด ×1.3; ข้อที่ต้นฉบับไม่มีช้อยเลย → แต่งเอง 5 ช้อย
8. stem: อังกฤษ ใกล้ต้นฉบับ ห้ามใบ้ (ห้ามวงเล็บแปลผลแลป, ห้ามชื่อ sign/โรคที่ต้องตีความเอง, ห้าม normal range); ต้นฉบับกำกวมจนตอบได้หลายช้อย → ระบุในตารางว่า "เติมใน stem ว่า …" ให้เหลือคำตอบเดียว + ⚠; ข้อที่ต้นฉบับเป็นคำถามสั้น ๆ ไม่ใช่เคส ให้ผู้เขียนทำเป็นเคสสั้น ๆ ได้ถ้าไม่เปลี่ยนสิ่งที่ถาม
9. ตารางต้องมีครบทุกช่องเหมือน SPEC76C: ข้อ/หน้า (หน้าในไฟล์โจทย์ + ถ้ามีไฟล์เฉลยแยกให้ใส่หน้าในไฟล์เฉลย page2), ต้นฉบับ (gray — ข้อความโจทย์+ช้อยต้นฉบับตรงตัว), ช้อยของเรา A–E → ans, คีย์ + ถอดโน้ต/คำอธิบายในไฟล์เฉลยให้ครบ + คำสั่งพิเศษ (เติมอะไร, ⚠ อะไร, guideline ที่ควรอ้าง)
10. เขียนผลเป็น `/home/claude/sx-mcq/parts/SPEC<ชุด>.md` (ชื่อไฟล์ตามที่ได้รับ) — แบ่ง Part ละ 18–20 ข้อ (จำนวน Part = ceil(จำนวนข้อ/20)) และสร้าง checker ของชุดนั้นที่ `/home/claude/sx-mcq/parts/check_<ชุด>.js` โดยคัดลอก `/home/claude/sx-mcq/parts/check_c.js` แล้วแก้ prefix รูป (q<prefix>_ / k<prefix>_), KS, set/ro/file/kfile

# งานผู้เขียนข้อสอบ — ชุด 74A/74C/74D/79C/79D (Gen Sx) + 79C Subspe (20 ต.ค. 2026)

repo: `/home/claude/ac-mdcu` (เอกสารเก่าเขียน `/home/claude/sx-mcq` = โฟลเดอร์เดียวกัน)

1. อ่าน SPEC ของชุดที่ได้รับ **ทั้งส่วนหัว + รูปแบบเอาต์พุต + กติกาเขียน + ตาราง Part ของตัวเอง** (และแถวท้ายไฟล์ "ข้อที่เกี่ยวข้องกัน" ถ้ามี) — ตารางคือคำตัดสินที่ตายตัว: ช้อย ลำดับช้อย คำตอบ คีย์ flag รูป ห้ามเปลี่ยน
2. ดูตัวอย่างระดับความละเอียดจากข้อที่ทำเสร็จแล้ว 2–3 ข้อใน `data/data_b13.js` (หรือ `data/data_b12.js`) ก่อนเขียน — เขียนให้ละเอียดเท่ากัน
3. เขียนไฟล์ part ตามชื่อที่ SPEC กำหนด (`parts/<code>_partN.js`) มีแค่รายการ `A({...}),` ต่อกัน ไม่มี header
4. ตรวจด้วย checker ของชุด `node parts/check_<ชุด>.js parts/<code>_partN.js` จนได้ `bad 0`
5. **"ข้อ" ตามด้วยตัวเลข = rid ในชุดนี้เท่านั้น ในทุกช่อง (รวม notes/flag)** — ระบบแปลงเป็นเลขข้อจริงตอนประกอบไฟล์; ถ้าจะพูดถึงเลขในต้นฉบับ ให้เขียน "เลข 4 ในต้นฉบับ" หรือ "แถว Hernia 2" (ห้ามเขียน "ข้อ 4" ที่หมายถึงเลขต้นฉบับ); ชุดอื่นให้เขียน "ข้อสอบชุด 77D เรื่องเดียวกัน"
6. ภาษา: เฉลยไทยปนศัพท์อังกฤษ, stem/ช้อยอังกฤษ formal; HTML ได้แค่ `<b>`; `&lt;` `&gt;`; ห้าม backtick; double-quote string escape `\"`
7. ข้อเท็จจริงทางการแพทย์: ใช้ guideline/ตำราฉบับล่าสุด ระบุชื่อ+ปีจริง ห้ามแต่งตัวเลขที่ไม่แน่ใจ
8. ห้ามแก้ไฟล์อื่นนอกจาก part ของตัวเอง (ห้ามแตะ data/, config, git, SPEC)

ตอบกลับสั้น ๆ: ไฟล์ที่เขียน, จำนวนข้อ, ผล checker, ข้อที่สงสัยในตาราง (ถ้ามี — rid + ประเด็น 1 บรรทัด) โดยยังเขียนตามตาราง

รูปแบบ `{"12": [ตัวพิมพ์, รูปในหน้า หรือ null, ลายมือ/ไฮไลต์], "s5": [...]}` — key สไลด์ = เลขหน้า (string) · ชีท = "s"+เลขหน้า
1. **ตัวพิมพ์: ครบทั้งหน้าทุกคำตามต้นฉบับ** (หัวข้อ `<b>…</b>` · bullet คั่นด้วย " · " หรือ `<br>` · ตารางเขียนเป็นแถว "หัว: ค่า" · สะกดตามต้นฉบับ แม้ผิด) · ห้ามสรุป ห้ามตัด
2. **รูปในหน้า:** บรรยายสิ่งที่เห็น (ภาพถ่ายผู้ป่วย/แผนภาพ/กราฟ/ตาราง/ป้ายในรูป) 1–3 ประโยค · ไม่มีรูป → null
3. **ลายมือ/ไฮไลต์:** ทุกจุดตามตำแหน่งจริง "ไฮไลต์เหลือง "…" · ลายมือข้าง … : <b>"ข้อความลายมือตรงตัว"</b>" · ลูกศร/วง/ขีดเส้นใต้บอกด้วย · ไม่มีเลย → สไลด์ "ไม่มีลายมือ · ไม่มีไฮไลต์" · ชีท (ตัวพิมพ์สแกน) → "ไม่มีลายมือ · ไม่มีไฮไลต์ (ชีทเป็นตัวพิมพ์สแกน)"
- สัญลักษณ์คณะ (❌ กากบาทแดง / 🟢 วงกลมเขียว / 🟡 สามเหลี่ยมเหลือง / 🔴 ดาวแดง) ถ้าเห็นให้เขียนท้ายช่องลายมือ "สัญลักษณ์คณะ: …"
- ห้ามใส่ชื่อนักศึกษา/ผู้โพสต์/ชื่อผู้ป่วย/HN (ถ้ามีในรูป ข้าม) · ใช้ `&lt;` แทน < ที่ไม่ใช่แท็ก
